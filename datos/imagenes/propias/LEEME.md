# Fotos propias

Coloca aqui fotos de las letras A, B, C y D (una letra por foto, fondo liso), en
subcarpetas por clase:

```
propias/A/foto1.jpg
propias/B/...
```

o sueltas con nombres que empiecen por la letra (`B_movil.jpg`). Despues:

```bash
python3 experimentos/exp12_imagenes_reales.py
```

El experimento las preprocesa y muestra que letra reconoce cada modelo. Para
entrenar con ellas, ver la seccion "Entrenar con fotos propias" del README.
